# StudentHub

These are my web development practicals for college, based on a website called StudentHub.

## Repository Structure

Each practical has its own folder, from `Practical1` to `Practical14`.

Practicals 1 to 10 build up the StudentHub website. Practicals 11 to 14 are small separate demos.

## Technologies Used

- HTML5
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Practicals

### Practical 1

- Sitemap and wireframes
- Plan the pages and navigation

### Practical 2

- StudentHub website
- Multiple HTML pages
- Navigation

### Practical 3

- Apply CSS to every page
- Colours, fonts and page layouts

### Practical 4

- Basic JavaScript and DOM
- Image slider
- Dark and light theme

### Practical 5

- Check form inputs using JavaScript and regex
- Check name, email, phone number and password

### Practical 6

- Load events from a JSON file using Fetch
- Search events and split them into pages
- Show loading and error messages

### Practical 7

- Handle the registration form using PHP
- Save registration details in a CSV file
- Run PHP using XAMPP

### Practical 8

- Create MySQL tables for students, events and registrations
- Connect tables using primary and foreign keys

### Practical 9

- Save registration details in MySQL
- Check if an email is already registered
- Store passwords using password_hash()

### Practical 10

- Login and logout using PHP sessions
- Separate student and admin dashboards
- Session timeout

### Practical 11

- Add, view, edit and delete students
- Search students and filter by course

### Practical 12

- Add, view, edit and delete events
- Upload event posters and check file type and size
- Change event status

### Practical 13

- PHP API that returns JSON
- Use Fetch to add, view, edit and delete students without reloading the page
- Show loading, success and error messages

### Practical 14

- Admin dashboard with database counts and latest registrations
- Show different menus and limit access based on the user's role
- Record admin actions in an audit log
